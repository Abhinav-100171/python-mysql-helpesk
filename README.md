# python-mysql-helpesk
Helpdesk ticketing system built using python and mysql

Python + MySQL Helpdesk Ticketing System

About

A helpdesk application developed using Python and MySQL to manage support tickets and track their progress.

Features

- User and admin roles
- Create and manage support tickets
- Assign tickets to support staff
- Update ticket status
- View ticket history
- Store ticket information in MySQL

Technologies Used

- Python
- MySQL
- SQL

How to Run

1. Install Python and MySQL.
2. Create the required database and tables.
3. Configure your database connection using your own local credentials.
4. Run "main.py".
